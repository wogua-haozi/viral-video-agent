# 前端设计说明

当前状态与后续任务见 [项目状态](project-status.md)；本机实际页面、主题与移动端结果见 [浏览器验收](../output/creator-pilot/ui-validation.json)。README 展示本轮重新生成的页面，历史截图仅作旧版记录。

## 产品与视觉定位

产品面向 B 站创作者：从赛道、竞品、标题、选题或脚本问题出发，阅读带来源的研究报告，并据此决定下一步创作。

本轮视觉以伦勃朗的暖色调与明暗层次为灵感，形成“创作者书房”。首页和工作台使用深棕黑环境、从右上方展开的暖金光感、薄框和留白；象牙白正文与衬线标题共同建立阅读层级。主要操作保持明确，报告中的表格、来源与任务状态优先保证可读性。

## 主题、颜色与字体

颜色集中在 `frontend/src/app/globals.css`，通过 Tailwind 语义 Token 使用。首次访问默认深色，`next-themes` 继续保留用户已有选择；浅色主题使用暖纸色，不改变操作与信息顺序。

| 类别 | Token / 样式 | 设计用途 |
|---|---|---|
| 页面与卡片 | `background`、`surface`、`card` | 深棕黑层次；浅色主题对应纸色与暖白 |
| 正文与说明 | `foreground`、`muted-foreground` | 象牙白正文、灰褐色辅助信息；浅色主题使用深棕文字 |
| 主要操作与引用 | `primary`、`ring` | 赭金色按钮、来源链接、焦点环 |
| 状态 | `success`、`warning`、`destructive` | 成功、部分完成与错误，同时配文字标签 |
| 明暗与边界 | `studio-hero`、`studio-frame`、`border` | 局部暖光、克制薄框与卡片分隔 |
| 标题 | `font-display` | Baskerville / Georgia 与本地中文宋体回退 |
| 正文 | 系统无衬线字体 | 长报告、输入内容和操作标签 |
| 编号与数据 | `font-mono`、`tabular-nums` | 证据编号、日期、任务标识和数值 |

字体全部使用系统回退，不在构建或浏览时下载在线字体。中文标题优先使用 Noto Serif CJK SC、Songti SC、STSong 或 SimSun；正文使用 PingFang SC、Microsoft YaHei 与系统字体。截图环境需要自行提供中文字体，产品代码不为截图环境增加依赖。

## 页面与操作

| 页面 | 本轮调整 |
|---|---|
| 首页 | 暖光主视觉、书房笔记构图、五种研究入口；示例明确标注为结构示意 |
| 登录与注册 | 统一暖色视觉，突出表单标签、错误和提交状态 |
| 工作台 | 突出待继续任务、最近研究和本月额度；侧栏沿用统一导航 |
| 新建分析 | 五种模板帮助描述问题；保留查询草稿与同一请求的提交标识；清楚说明深度模式与额度 |
| 任务详情 | 加载后持续保留内容；后台轮询错误使用页内提示；停止中的任务继续更新状态 |
| 候选确认 | 逐项确认、排除或待定；提供下一项入口；同一快照的选择保留在当前标签页会话中 |
| 报告与分享 | 保留完整正文及程序附录；结论和证据详情可展开；引用直接定位来源卡片 |

## 报告阅读与来源

报告正文使用稳定阅读宽度、较宽行距和局部横向滚动表格。详细结论与证据视图默认折叠，读者可以按需核对；点击已知证据编号会展开对应区域。公开分享使用同一阅读组件，继续由公开 API 控制可见字段。

证据卡片显示实际字段值、原始来源、发布时间和采集时间。缺失数据与真实的零值分开显示；转写片段按需展开。模型信心标为“模型自评”，并注明未经独立校准。无有效 HTTP(S) 来源时不生成外链。

打印使用浅色正文，隐藏导航、操作按钮和重复的交互详情；正文中保留程序生成的结论索引与来源附录。

## 响应式与可访问性

- 桌面侧栏在手机端变为菜单；多列内容随视口收拢，长标题与 URL 可以换行，宽表格只在自身区域滚动。
- 主要点击目标保持约 44px；导航、表单、候选项与报告引用支持键盘操作和可见焦点。
- 所有任务状态同时使用文字，不依赖颜色区分。
- 背景刷新失败使用非阻断提示，不替换已经加载的表单；提交、取消与重新连接有独立反馈。
- `prefers-reduced-motion` 下关闭平滑滚动并压缩动画时间；页面没有持续运动背景。

## 实现范围

沿用 Next.js、Tailwind、Radix UI、Lucide 与 `next-themes`，没有新增 UI、动画或图片依赖。暖光和细纹由 CSS 实现，标志沿用项目原生 SVG 并调整暖色。路由与认证入口保留，后端新增的停止状态由 API 明确提供。
