# 前端设计说明

视觉基线：2026-10-18；任务交互补强：2026-10-20。当前状态与后续任务见 [项目状态](project-status.md)；视觉、主题与移动端基线见 [10/18 浏览器验收](../output/soft-ui-20261018/ui-validation.json)。README 保留准确反映当前视觉的真实截图，10/17 书房版仅作历史记录。

## 产品与视觉定位

产品面向 B 站创作者：从赛道、竞品、标题、选题或脚本问题出发，阅读带来源的研究报告，并据此决定下一步创作。

按最新设计方向，借鉴 Apple 产品界面的留白、克制层级和柔和表面。暖白与石墨灰构成主要背景，蓝色只用于操作、选中和引用；系统无衬线标题、轻边界与圆角替代先前的衬线字、金色光效和装饰纹理。首页突出一个开始入口，工作台突出任务，报告优先保证正文和来源可读。

## 主题、颜色与字体

颜色集中在 `frontend/src/app/globals.css`，通过 Tailwind 语义 Token 使用。首次访问默认浅色，`next-themes` 继续保留已有选择；深色使用石墨灰，不改变操作与信息顺序。

| 类别 | Token / 样式 | 设计用途 |
|---|---|---|
| 页面与卡片 | `background`、`surface`、`card` | 暖白与白色卡片；深色对应石墨灰层次 |
| 正文与说明 | `foreground`、`muted-foreground` | 浅色为近黑与中灰，深色为浅灰与辅助灰 |
| 主要操作与引用 | `primary`、`ring` | 蓝色按钮、来源链接、可见焦点环 |
| 状态 | `success`、`warning`、`destructive` | 成功、部分完成与错误，同时配文字标签 |
| 明暗与边界 | `surface`、`border`、`input` | 卡片边界较轻；输入框边界单独保证对比；圆角 14 / 20 / 28px |
| 标题 | `font-display` | 系统无衬线，使用字号和字重组织层级 |
| 正文 | 系统无衬线字体 | 长报告、输入内容和操作标签 |
| 编号与数据 | `font-mono`、`tabular-nums` | 证据编号、日期、任务标识和数值 |

字体全部使用系统回退，不下载在线字体。优先平台系统字体，Windows 使用 Segoe UI 与 Microsoft YaHei，macOS 使用系统字体与 PingFang SC。主要按钮采用胶囊形，表单保持明确标签；卡片阴影很轻，浮层使用独立的阴影层级。

## 页面与操作

| 页面 | 本轮调整 |
|---|---|
| 首页 | 居中标题、留白、单份报告结构预览、五种研究入口；保留演示边界 |
| 登录与注册 | 居中单表单，移除宣传侧栏；保留错误、密码可见切换和返回目标 |
| 工作台 | 去掉大型宣传横幅；单行导航，突出待继续任务、最近研究和本月额度 |
| 新建分析 | 五种模板帮助描述问题；保留查询草稿与同一请求的提交标识；清楚说明深度模式与额度 |
| 任务详情 | 后台轮询错误保留内容；停止中继续更新状态。重试响应不确定时核对服务端并恢复轮询；未决修订按账号/源任务/内容在当前标签页保存，503/响应丢失后刷新仍复用幂等键，明确成功才清除 |
| 候选确认 | 逐项确认、排除或待定；提供下一项入口；同一快照的选择保留在当前标签页会话中 |
| 报告与分享 | 保留完整正文及程序附录；结论和证据详情可展开；引用直接定位来源卡片 |

## 报告阅读与来源

报告正文使用稳定阅读宽度、较宽行距和局部横向滚动表格。详细结论与证据视图默认折叠，读者可以按需核对；点击已知证据编号会展开对应区域。公开分享使用同一阅读组件，继续由公开 API 控制可见字段。

证据卡片显示实际字段值、原始来源、发布时间和采集时间。缺失数据与真实的零值分开显示；转写片段按需展开。模型信心标为“模型自评”，并注明未经独立校准。无有效 HTTP(S) 来源时不生成外链。

打印使用浅色正文，隐藏导航、操作按钮和重复的交互详情；正文中保留程序生成的结论索引与来源附录。

## 响应式与可访问性

- 桌面侧栏在手机端变为菜单；多列内容随视口收拢，长标题与 URL 可以换行，宽表格只在自身区域滚动。
- 主要点击目标保持约 44px；导航、表单、候选项与报告引用支持键盘操作和可见焦点。
- 所有任务状态同时使用文字，不依赖颜色区分。
- 背景刷新失败使用非阻断提示，不替换已经加载的表单；提交、取消与重新连接有独立反馈。
- `prefers-reduced-motion` 下关闭平滑滚动并压缩动画时间；页面没有持续运动背景。
- 实际检查 320px / 375px 手机、768px 平板和桌面；首页 200% 文字放大可用，平板导航改用折叠菜单。实测普通正文/辅助字/主要链接和按钮文字不低于 4.5:1，输入边界不低于 3:1；结果保存在浏览器 JSON 中。这些针对性检查不代表全面无障碍认证。

## 实现范围

沿用 Next.js、Tailwind、Radix UI、Lucide 与 `next-themes`，没有新增依赖。项目 SVG 保留视频/趋势含义，统一为蓝白标志。API、路由、认证、幂等、额度、候选确认、报告引用与后端模型开关语义未改。
