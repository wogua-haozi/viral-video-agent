## 产品与视觉定位

产品面向 B 站创作者：从赛道、竞品、标题、选题或脚本问题出发，阅读带来源的研究报告，并据此决定下一步创作。

借鉴 Apple 界面的留白、清晰层级与克制材质，应用于浏览器中的创作者研究工具。浅色采用中性浅灰页面与白色内容表面，深色采用石墨层次；蓝色集中用于主要操作、引用与焦点，状态同时保留文字。通过字号、字重、间距和轻边界组织内容，减少重复说明与装饰。

首页的报告结构预览呈现“样本 → 观察 / 推断 / 建议”的产品特点；工作台优先展示需要继续的研究，报告保持完整正文，按需展开结论和来源。沿用网页导航与已保存的深浅主题选择，不照搬原生桌面菜单或增加新的交互流程。

## 主题、颜色与字体

颜色集中在 `frontend/src/app/globals.css`，通过 Tailwind 语义 Token 使用。首次访问默认浅色，`next-themes` 继续保留已有选择；深色使用石墨灰，不改变操作与信息顺序。

| 类别 | Token / 样式 | 设计用途 |
|---|---|---|
| 页面与卡片 | `background`、`surface`、`card` | 浅色页面为 `hsl(240 11% 96.5%)`，内容表面为白色；深色页面为 `hsl(240 5% 8.5%)`，表面以石墨灰区分 |
| 正文与说明 | `foreground`、`muted-foreground` | 浅色为近黑与中灰，深色为浅灰与辅助灰 |
| 主要操作与引用 | `primary`、`ring` | 蓝色按钮、来源链接、可见焦点环 |
| 状态 | `success`、`warning`、`destructive` | 成功、部分完成与错误，同时配文字标签 |
| 明暗与边界 | `surface`、`border`、`input` | 卡片边界较轻，输入框边界独立保证对比；圆角 Token 为 `.75rem` / `1.375rem` / `2rem`，默认根字号下约 12 / 22 / 32px |
| 标题 | `font-display` | 系统无衬线，使用字号和字重组织层级 |
| 正文 | 系统无衬线字体 | 长报告、输入内容和操作标签 |
| 编号与数据 | `font-mono`、`tabular-nums` | 证据编号、日期、任务标识和数值 |

字体全部使用系统回退，不下载在线字体。优先平台系统字体，Windows 使用 Segoe UI 与 Microsoft YaHei，macOS 使用系统字体与 PingFang SC。主要按钮采用胶囊形，表单保持明确标签；卡片阴影很轻，浮层使用独立的阴影层级。

`.navigation-material` 仅用于导航层：默认使用 88% 背景填充与 20px 背景模糊；`.modal-scrim` 统一公共菜单、工作台菜单和对话框遮罩。报告正文、卡片与输入框使用稳定表面，不叠加玻璃效果。

| 报告与分享 | 保留完整正文及程序附录；结论和证据详情可展开；引用直接定位来源卡片 |

## 报告阅读与来源

报告正文使用稳定阅读宽度、较宽行距和局部横向滚动表格。正文移动端为 `.9375rem`、较宽视口为 `1rem`，随根字号放大。详细结论与证据视图默认折叠，原生 `summary` 支持 Enter / Space；点击已知证据编号或打开带证据片段的 URL，会展开对应区域并定位。公开分享使用同一阅读组件，继续由公开 API 控制可见字段。

证据卡片显示实际字段值、原始来源、发布时间和采集时间。缺失数据与真实的零值分开显示；转写片段按需展开。模型信心标为“模型自评”，并注明未经独立校准。无有效 HTTP(S) 来源时不生成外链。

打印使用浅色正文，隐藏导航、操作按钮和重复的交互详情；正文中保留程序生成的结论索引与来源附录。

## 响应式与可访问性

- 桌面侧栏在手机端变为菜单；多列内容随视口收拢，长标题与 URL 可以换行，宽表格只在自身区域滚动。
- 主要点击目标保持至少约 44px；导航、表单、候选项与报告引用支持键盘操作和可见焦点。公共/工作台菜单保留 Tab / Shift+Tab 焦点循环与 Escape 返回触发按钮。
- 所有任务状态同时使用文字，不依赖颜色区分。
- 背景刷新失败使用非阻断提示，不替换已经加载的表单；提交、取消与重新连接有独立反馈。
- `prefers-reduced-motion` 下关闭平滑滚动，动画/过渡压缩至 `.01ms` 或关闭；页面没有持续运动背景。本轮检查真实菜单的计算样式，不仅依赖截图禁用动画。
- 支持 `prefers-reduced-transparency` 的浏览器使用实色导航，菜单/对话框遮罩去掉模糊、改为 70% 深色遮罩；增加对比度时加强边界与辅助文字。Chromium 通过 CDP 实际启用减少透明度，核对媒体查询、导航以及三类遮罩的计算样式。
- 本轮检查 320px / 375px 手机、768px 平板和桌面；首页及展开后的报告均检查 200% 文字。报告在 320px 下实际放大正文后无页面横向溢出。测试等待根字号确实放大/恢复后才测量，不用固定等待或降低字号断言。
- 浅/深主题已测文字 Token 配对的最低对比分别约 5.61:1 / 6.29:1，输入边界约 3.42:1 / 3.45:1，满足本次 4.5:1 / 3:1 阈值；完整数值见本轮 JSON。这些针对性检查不等于覆盖所有叠加场景、浏览器或全面无障碍认证。
